MNIST Digit Classifier

A neural-network experiment that turns a handwritten mark into a prediction, making the gap between pixels and classification tangible.

TYPEPYTHON / PYTORCH / ML
FOCUSINPUT + PREDICTION
THE QUESTIONWhat does a model actually see?
INPUT + PREDICTION
28×28PIXELS → MODEL → DIGIT
WHAT I BUILT

A neural network trained on the MNIST handwritten-digit dataset, with support for evaluating and predicting custom digit input.

HOW IT WORKS

A drawing is represented as pixel values, normalized into the model input shape and passed through the trained network. The result is a probability distribution over the ten digit classes, rather than a single unexplained label.

WHAT I LEARNED
REFLECTION

Small changes in the input can change the prediction. Building the classifier made the relationship between data representation, model architecture and confidence much more concrete.
