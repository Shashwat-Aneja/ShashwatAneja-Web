01 / OVERVIEW

A personal website, not a tracking platform.

This website is the personal developer portfolio of Shashwat Aneja. It exists to present software, games, experiments, interactive studies, writing and other personal work.

The website is not operated as an advertising platform and does not intentionally build advertising profiles from visitors.

02 / INFORMATION

Information you choose to provide.

Most of the portfolio can be explored without creating an account or submitting personal information.

If you contact Shashwat through email, LinkedIn, GitHub or another external service, the information you voluntarily provide is processed by that service and may also be visible to Shashwat as part of the communication.

This website does not currently operate a server-side account system or a database containing visitor profiles.

03 / LOCAL STORAGE

Your browser remembers small preferences.

The website may use browser localStorage to remember interface preferences. This currently includes the selected visual theme and, where applicable, whether a privacy notice has been dismissed.

These preferences are stored locally by your browser. They are not intended to function as a personal identity profile and are not used by this website to identify you.

In simple terms: changing the site's atmosphere can be remembered between visits, but the website does not need an account to do that.

04 / WORKSPACE

Interactive tools run in your browser.

Some portfolio Workspace features allow you to draw pixels, manipulate images, generate procedural scenes or interact with browser-based demonstrations.

Where a Workspace explicitly states that processing occurs locally, the operation is performed in your browser rather than being intentionally uploaded to a server by the portfolio.

You should still avoid using highly sensitive, confidential or private material in any online tool unless you have independently verified its behaviour and security requirements.

05 / EXTERNAL SERVICES

Some links leave this website.

The portfolio links to external services including GitHub and LinkedIn. Those services operate independently and have their own privacy policies, cookies, analytics systems and data practices.

Shashwat Aneja does not control the privacy practices of external websites and cannot guarantee how those services process data after you leave this website.

06 / RETENTION

No unnecessary visitor database.

The portfolio does not currently maintain a dedicated visitor account database or intentionally retain ordinary browsing information as a personal profile.

Information sent directly to Shashwat through email or an external communication platform may remain available in that service according to its own retention and deletion practices.

07 / CHANGES

This page can evolve with the website.

The website, its technologies and its data practices may change as new features are introduced. This page will be updated when those changes materially affect the way information is handled.

Continued use of the website after an updated version of this policy is published means that you have had an opportunity to review the revised information.
